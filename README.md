## 이 사이트는 공개입니다

기존 [naru-review](https://github.com/POGNARU/naru-review)와 정반대입니다.

| | naru-review (사적) | 이 사이트 (공개) |
|---|---|---|
| robots | `Disallow: /` 전면 차단 | 없음 |
| 메타 | 모든 페이지 `noindex` | 없음 (검색 노출이 목적) |
| 성격 | 혼자 보는 기록 | 매주 발행하는 콘텐츠 |

**`robots.txt`를 만들지 마세요. `noindex` 메타도 넣지 마세요.** 검색에 잡히는 것이 이 사이트의 목적입니다.

사적 판(naru-review)은 2026-07-31 이후 동결됐고, **2026-08-01에 GitHub Pages를 껐습니다**(`gh api -X DELETE repos/POGNARU/naru-review/pages`). `pognaru.com/naru-review/`는 이제 404입니다.

> **왜 껐나**: 그 사이트에는 여과 없는 원본 회고 열세 편이 올라가 있었습니다. `noindex`로 검색만 막혀 있었을 뿐, 주소를 아는 사람은 누구나 읽을 수 있는 상태였습니다. 레포를 비공개로 돌려도 Pages로 나간 **페이지 자체는 공개**라서, 잠그는 것만으로는 해결되지 않습니다. 파일과 깃 기록은 로컬(`★개발 도구함/naru-review/`)에 그대로 있고, 이관 작업의 재료로 씁니다.

앞으로 회고는 공개판만 만듭니다. **웹에서 읽히는 회고는 이 사이트 한 곳뿐입니다.**


**프록시(주황 구름)를 반드시 꺼야 합니다 — DNS only.** 켜면 GitHub이 HTTPS 인증서를 발급하지 못하고 무한 리다이렉트에 빠집니다. Cloudflare에서 산 도메인은 프록시가 기본 켜짐이라 특히 주의하세요.

`CNAME` 파일은 **이 레포에만** 둡니다. 개별 프로젝트 레포에는 넣지 마세요 — 자동으로 따라옵니다.

## 새 회고 추가하는 법

1. `weekly/YYMMDD.html`을 기존 회고에서 복제 (파일명은 **그 주 일요일** 날짜)
2. `<head>`의 title·description·canonical·og를 그 주 내용으로 교체
3. 본문 교체 — 기록 스트립 / 새벽의 흐름 / 새벽이 남긴 문장들 / 저녁의 결 / 이번 주 결 / 이번 주의 씨앗 / 핵심 문장 / 저자 블록
   - 저녁 저널이 없는 주는 「저녁의 결」 섹션을 통째로 뺍니다
   - 저녁 타임라인은 `<div class="timeline eve">` — 점이 살구로 바뀝니다 (새벽은 호박)
4. `weekly/index.html`의 해당 월 블록 **맨 위**에 카드 추가. 날짜 배지는 그 주 **월요일**
5. 위 공개 안전 원칙으로 한 번 더 훑기
6. 커밋 & 푸시

**분석 범위는 언제나 월요일~일요일 7일**입니다. 햇살은 한 주를 월요일에 시작해 일요일에 마칩니다.

## 월간 회고 추가하는 법

1. `weekly/YYMM-monthly.html`을 **직전 월간 회고에서 복제** (예: 8월분 → `weekly/2608-monthly.html`). 주간(`YYMMDD.html`)과 구분하려고 `-monthly`를 붙입니다
2. CSS는 `base.css` → `weekly.css` → **`monthly.css`** 세 장. 그래프 스타일은 이미 `monthly.css`에 있으니 새로 만들지 마세요
3. 본문 교체 — 기록 스트립 / 그래프 / 새벽의 흐름(**주차별**) / 저녁의 결 / 새벽이 남긴 문장들 / 이 달의 결 / 이 달의 씨앗 / 핵심 문장 / 저자 블록
4. `weekly/index.html`의 해당 월 블록 **맨 위**에 월간 카드(`.mc`)를 추가. **`.range`는 그 달 전체**(`2026.08.01 — 08.31`)로 둡니다 — 월간 카드의 날짜는 "며칠을 분석했나"가 아니라 **"어느 달이냐"**는 뜻입니다
5. 아래 공개 안전 원칙으로 한 번 더 훑기
6. **푸시하지 말고 확인 요청** (B안)

### 그래프 규칙

**색은 `base.css`의 `--g1`~`--g5`, 비교군은 `--g-compare`.** 월별 계절색을 새로 만들지 마세요.

- **키워드는 날짜 수가 아니라 비율(%)로 견줍니다.** 달마다 기록한 편수가 달라(5월 16편, 6월 19편, 7월 24편) 절대 수치로는 비교가 성립하지 않습니다
- **편수는 폴더를 전부 훑어 세고, 앞 달 페이지의 비교값도 함께 고칩니다.** 2026-08-01에 6월분을 이관하며 원본이 `260617`을 통째로 빠뜨린 것을 발견했습니다(17편 → 실제 19편/18일). 7월 페이지가 그 17편을 비교 기준으로 쓰고 있어 키워드 비율 열한 갈래를 모두 다시 계산했습니다. **한 달을 고치면 다음 달 페이지도 반드시 함께 고쳐야 합니다**
- **결측이 많은 항목은 뺍니다.** 2026년 7월은 글쓰기 시간이 적힌 날이 24편 중 이레뿐이었고 그 이레가 앞뒤로 갈려 있어, 그리면 통계가 아니라 지목이 됩니다
- **어두운 시기가 낀 달은 일별 대신 주 단위로 묶습니다.** 일별 그래프는 특정 날짜의 급락을 그대로 드러냅니다
- 그래프는 `.scroll-x`로 감쌉니다. 좁은 화면에서 **그래프만** 가로로 흐르고 본문은 넘치지 않습니다

## 독서 자료 추가하는 법

`/reading/`은 두 갈래를 한자리에 놓습니다.

- **나루의 밤** — 클래스 토론 자료. 실물은 [bamnaru](https://github.com/POGNARU/bamnaru) 레포에 있고 여기선 링크만 겁니다. **카드 옆 「전체 커리큘럼 →」 링크는 반드시 유지하세요.** 그게 있어야 방문자가 전체 커리를 확인합니다
- **개인 독서 기록** — 개별 페이지가 이 폴더에 삽니다

**독서 페이지는 사이트 팔레트를 따르지 않습니다.** 그 책 표지의 결로 짓습니다 (『절창』이 보라 계열인 이유). 목록 페이지만 포근나루 화면판입니다. 다만 표지에서 뽑은 색이라도 **본문 대비 4.5:1**은 지켜야 합니다.

파일명은 `YYMMDD-제목.html`. 새로 추가하면 `reading/index.html`의 해당 섹션에 카드를 얹고 `.cnt` 숫자를 고칩니다.

## 책 페이지 표지 (2026-08-01)

`/assets/cover-sunlit-days-1.jpg` — **720×1000, 92KB**. 볼트에 표지 원본이 없어 YES24 상품 이미지(864×1200)를 내려받아 줄였습니다. 알라딘판은 500×694라 작습니다.

`.cover`의 `aspect-ratio`는 **파일 비율과 같아야 합니다**(지금 `720 / 1000`). `object-fit:cover`라 비율이 어긋나면 좌우가 잘려 제목 글자가 날아갑니다. 표지를 갈아 끼울 때 CSS의 비율도 함께 고치세요.

`og:image`도 이 파일입니다. 카카오·슬랙에 링크를 붙이면 표지가 미리보기로 뜹니다.

## 문의 동선 (카카오채널)

문의는 **카카오채널 '포근나루' 1:1 채팅** 한 곳으로 모읍니다 — https://pf.kakao.com/_AxbxmxhX/chat

**두 층으로 나눠 둡니다. 모든 페이지에 버튼을 달지 마세요.**

| 층 | 어디에 | 무엇을 |
|---|---|---|
| 버튼 `.kakao-btn` | 현관 · 클래스 목록 · 선릿모닝 · 나루의 밤 | 물어보고 싶어지는 자리에만. 알약 버튼 |
| 푸터 링크 「문의」 | 사이트 푸터가 있는 모든 페이지 | 조용한 한 줄. 회고·독서는 읽는 자리라 버튼은 튑니다 |

`.kakao-btn`은 신청 버튼(`.cta .btn`, 진테라코타 채움)보다 **한 단 낮은 부 버튼**입니다. 테두리만 두르는 이유는 한 화면에서 신청과 문의가 힘을 겨루지 않게 하기 위함입니다. 말풍선 아이콘만 호박이고 글자는 진테라코타입니다(호박은 글자 금지).

`reading/260726-principia.html`과 `260730-jeolchang.html`은 **책 표지 팔레트를 따르는 예외 페이지**라 사이트 푸터가 없습니다. 여기엔 문의 링크를 넣지 않습니다.

카카오채널 상담은 **평일 06시~18시**이고 주말·공휴일은 운영하지 않습니다. 버튼 옆 안내 문구(`.kakao-hours`)에 그 시간을 반드시 함께 적습니다.
