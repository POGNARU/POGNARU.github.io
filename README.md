## 이 사이트는 공개입니다

기존 [naru-review](https://github.com/POGNARU/naru-review)와 정반대입니다.

| | naru-review (사적) | 이 사이트 (공개) |
|---|---|---|
| robots | `Disallow: /` 전면 차단 | 없음 |
| 메타 | 모든 페이지 `noindex` | 없음 (검색 노출이 목적) |
| 성격 | 혼자 보는 기록 | 매주 발행하는 콘텐츠 |

**`robots.txt`를 만들지 마세요. `noindex` 메타도 넣지 마세요.** 검색에 잡히는 것이 이 사이트의 목적입니다.

사적 판(naru-review)은 2026-07-31 이후 동결됐습니다. 앞으로 회고는 공개판만 만듭니다.

### 공개 안전 원칙

원재료가 사적인 새벽 글(모닝페이지·몽롱쓰기)입니다. **원문은 절대 이 레포에 들어오지 않습니다.** 볼트에서 읽어 회고만 짓습니다.

- 제3자 실명·사생활 금지 → 익명화("한 사람", "가까운 이"), 사건은 윤곽만
- 2026년 1~2월 가족 관련 서술은 한 단계 더 흐리게 (검색으로 낯선 사람이 닿는 자리라서)
- 본인 감정·깨달음은 그대로 둡니다. 덜어내는 것은 타인의 사생활이지 저자의 진심이 아닙니다
- 식구 이름(호수·나무·김리 등)이나 내부 도구명은 낯선 독자가 이해할 수 있게 풀어 씁니다
- 3인칭("다현씨는…")이 아니라 1인칭으로 씁니다

공개 범위는 **2026년 1월부터**입니다. 연간 회고(2023~2025)는 공개하지 않습니다.

## 도메인 (2026-07-31)

`pognaru.com` — Cloudflare Registrar 등록. **레포 13개가 전부 이 도메인 아래로 따라옵니다** (`pognaru.com/dawn/`, `/bamnaru/`, `/sunlit-morning/` …). 옛 `pognaru.github.io` 주소는 자동 리다이렉트되니 그동안 뿌린 링크는 안 깨집니다.

DNS는 Cloudflare에서 관리합니다. apex(`@`)에 A 레코드 네 개:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**프록시(주황 구름)를 반드시 꺼야 합니다 — DNS only.** 켜면 GitHub이 HTTPS 인증서를 발급하지 못하고 무한 리다이렉트에 빠집니다. Cloudflare에서 산 도메인은 프록시가 기본 켜짐이라 특히 주의하세요.

`CNAME` 파일은 **이 레포에만** 둡니다. 개별 프로젝트 레포에는 넣지 마세요 — 자동으로 따라옵니다.

도메인이 붙은 뒤 canonical·og:url·내부 링크를 전부 새 도메인으로 옮겼습니다. 옛 주소를 정본으로 선언해두면 검색엔진이 어느 쪽을 본판으로 볼지 헷갈립니다.

**미완**: `www` CNAME(이름 `www`, 대상 `pognaru.github.io`, 프록시 끔)이 아직 없습니다. `www.pognaru.com`으로 들어오는 사람만 못 닿고 나머지는 정상입니다.

## 새 회고 추가하는 법

1. `weekly/YYMMDD.html`을 기존 회고에서 복제 (파일명은 **그 주 일요일** 날짜)
2. `<head>`의 title·description·canonical·og를 그 주 내용으로 교체
3. 본문 교체 — 기록 스트립 / 새벽의 흐름 / 새벽이 남긴 문장들 / 저녁의 결 / 이번 주 결 / 이번 주의 씨앗 / 핵심 문장 / 저자 블록
   - 저녁 저널이 없는 주는 「저녁의 결」 섹션을 통째로 뺍니다
   - 저녁 타임라인은 `<div class="timeline eve">` — 점이 살구로 바뀝니다 (새벽은 호박)
4. `weekly/index.html`의 해당 월 블록 **맨 위**에 카드 추가. 날짜 배지는 그 주 **월요일**
5. 위 공개 안전 원칙으로 한 번 더 훑기
6. 커밋 & 푸시

**분석 범위는 언제나 월요일~일요일 7일**입니다. 햇살은 한 주를 월요일에 시작해 일요일에 마칩니다.

## 독서 자료 추가하는 법

`/reading/`은 두 갈래를 한자리에 놓습니다.

- **나루의 밤** — 클래스 토론 자료. 실물은 [bamnaru](https://github.com/POGNARU/bamnaru) 레포에 있고 여기선 링크만 겁니다. **카드 옆 「전체 커리큘럼 →」 링크는 반드시 유지하세요.** 그게 있어야 방문자가 전체 커리를 확인합니다
- **개인 독서 기록** — 개별 페이지가 이 폴더에 삽니다

**독서 페이지는 사이트 팔레트를 따르지 않습니다.** 그 책 표지의 결로 짓습니다 (『절창』이 보라 계열인 이유). 목록 페이지만 포근나루 화면판입니다. 다만 표지에서 뽑은 색이라도 **본문 대비 4.5:1**은 지켜야 합니다.

파일명은 `YYMMDD-제목.html`. 새로 추가하면 `reading/index.html`의 해당 섹션에 카드를 얹고 `.cnt` 숫자를 고칩니다.

## 클래스 페이지 고치는 법 (2026-08-01 개설)

`/class/`는 **홍보물이 아니라 안내판**입니다. 처음 오는 사람에게는 소개가 되고, 이미 함께하는 분에게는 확인하는 자리가 됩니다. 그래서 카메라·소리·준비물·결석처럼 그동안 1:1 문구로 되풀이하던 안내를 여기에 두었습니다. 앞으로 문의가 오면 이 페이지 링크로 답할 수 있습니다.

### 선릿모닝 — 절대 넣지 않는 것

| 넣지 않음 | 이유 |
|---|---|
| 계좌번호 | 공개 페이지입니다. 계좌는 신청 후 문자로만 |

| 중간 합류의 기간·비용 조건 | 1:1 상담에서만 안내합니다 |

**운영 기준의 정본은 실제 네이버 폼**(https://naver.me/GcAknJnT)이고, 그다음이 볼트 `클로드 에이전트/나무의 기록/선릿모닝/선릿모닝 신청 안내.md`입니다. 이 페이지는 그 둘을 따라갑니다. 어긋나면 폼이 맞습니다.

**「이번 달 일정」 블록은 달마다 손봅니다.** 규칙에서 역산하지 마세요 — 월 시작일은 1일도 아니고 월요일도 아닙니다(8월은 3일 월요일, 9월은 1일 화요일). 새 달 일정은 다현씨에게 확인하고 적습니다.
